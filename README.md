# Personal Repository of Projects and About Info

This repo contains the site source for `gamrix.github.io`.

## Windows Setup

Open PowerShell in the repo root and run:

```powershell
nvm install lts
nvm use lts
npm install -g pnpm
pnpm install
```

## Common Commands

Start the local dev server:

```powershell
pnpm dev
```

Run the production build:

```powershell
pnpm build
```

Run tests:

```powershell
pnpm test
```
